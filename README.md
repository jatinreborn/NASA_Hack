
# OUTPOST — Mission Trainer

A lunar and Mars outpost survival game built for the **NASA Space Apps Challenge 2026**.

## About

Humanity is preparing to establish settlements beyond Earth. Can you keep your crew alive?

OUTPOST is a single-player, turn-based survival simulation in which players manage an extraterrestrial outpost, balance essential resources, and make decisions that affect the survival of their crew.

## Current Features

- Moon and Mars destination selection
- Mission initialization
- Mission Control dashboard
- Water, oxygen, food and power monitoring
- Water recycling system
- Greenhouse operations
- Solar power generation
- Turn-based mission progression
- Basic survival win and failure conditions

## Tech Stack

- React
- JavaScript
- Vite
- CSS

## Run Locally

Make sure Node.js and Git are installed.

Clone the repository:

```bash
git clone https://github.com/jatinreborn/NASA_Hack.git
```

Enter the project directory:

```bash
cd NASA_Hack
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal, usually:

`http://localhost:5173/`
